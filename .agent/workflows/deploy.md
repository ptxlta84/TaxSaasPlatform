description: Deploy the application using the standardized safe workflow
---

This workflow executes the `simple-deploy.sh` script to lint, test, build, and deploy the application.
It is the MANDATORY method for all deployments.

1. Ensure you are in the project root.
2. Run the deployment script using bash (required for the script).

```bash
bash simple-deploy.sh
```

Follow the interactive prompts (confirm changes, enter commit message).
